Python-скрипт для періодичного збору телеметрії системи (Linux) із записом у CSV-файл та керуванням GPIO за температурним порогом. Може працювати як сервіс systemd.

Можливості
- Вимірювання кожні 5 секунд:
  - температура CPU;
  - завантаження CPU, %;
  - використання RAM, %.
- Запис результатів у `telemetry.csv`.
- Керування GPIO (`/dev/gpiochip0`, лінія 17): при температурі ≥ 60 °C подається HIGH (наприклад, для світлодіода), при нормалізації або відсутності датчика — LOW.
- Коректне завершення за сигналами `SIGINT` / `SIGTERM` зі звільненням GPIO.
- Якщо датчик температури недоступний, у CSV записується `N/A`.
- Якщо бібліотека `gpiod` або GPIO-пристрій відсутні (наприклад, у WSL), скрипт продовжує працювати без керування GPIO.
